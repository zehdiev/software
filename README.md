# Офис програми – упражнения

Уеб приложение с уроци и упражнения по **Windows и File Explorer, Word, Excel и PowerPoint** за курса „Административни и офис дейности“ (041501, I СПК). Уроците следват учебния план (Б2 – Дигитални технологии, А3 1.3 – ИКТ).

- 37 урока: Windows (9), Word (11), Excel (9), PowerPoint (8)
- Всеки урок: кратка теория, указания за телефон и компютър, упражнение в симулатор и автоматична проверка
- Работи на телефон и компютър; след първото отваряне работи и без интернет
- Напредъкът се пази в браузъра на устройството

## Публикуване в GitHub Pages
1. Качете всички файлове от тази папка в корена на ново хранилище (repository).
2. **Settings → Pages → Build and deployment → Deploy from a branch**, изберете `main` и папка `/ (root)`.
3. След минута-две приложението е на `https://<потребител>.github.io/<хранилище>/`.

## Обновяване
Ако смените `index.html`, увеличете номера `CACHE` в `sw.js` (напр. `aod-soft-v2`), за да получат всички новата версия.
